# Task 2: Data Visualization and Storytelling

## Objective
The objective of this task is to analyze sales data and present important business insights using simple data visualization techniques.

## Tools Used
- Python
- Pydroid 3

## Dataset
A sample sales dataset was created directly in the Python program.

The dataset contains:
- Monthly sales data
- Category-wise sales data

## Visualizations
The project presents sales information using:
- Monthly sales analysis
- Category-wise sales analysis
- Text-based sales charts

## Key Insights
1. May recorded the highest monthly sales.
2. January recorded the lowest monthly sales.
3. Technology had the highest category sales.
4. Sales generally increased over the months.

## How to Run
1. Open Pydroid 3.
2. Create a new Python file.
3. Copy the provided Python code.
4. Run the program.
5. View the sales analysis in the output screen.

## Output
The program displays:
- Monthly sales
- Category-wise sales
- Highest and lowest sales
- Important business insights

## Conclusion
This project demonstrates how sales data can be analyzed and presented clearly to identify important business trends and insights.
